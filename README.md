
# Bank Simulation mit Java

Dieses Projekt ist eine objektorientierte Bank-Simulation. Es bietet ein robustes Transaktionssystem, eine grafische Benutzeroberfläche und persistente Datenspeicherung.

## Features & Architektur

* **Objektorientiertes Design:** Strukturierte Modellierung von Banken, Konten und verschiedenen Transaktionsarten.
* **Grafische Benutzeroberfläche (GUI):** Eine benutzerfreundliche Oberfläche, die mit **JavaFX** (mittels FXML) erstellt wurde, um Daten und Transaktionen komfortabel einzugeben und zu verwalten.
* **Datenpersistenz:** Um Datenverlust zu vermeiden, werden alle Kontostände und Transaktionsverläufe dauerhaft mittels **JSON** gespeichert und beim Neustart wieder geladen.
* **Qualitätssicherung:** Die Kernfunktionen und das Transaktionssystem sind durch automatisierte **JUnit**-Tests abgesichert.
* **Build-Management:** Das Projekt wird mit **Maven** strukturiert, um Abhängigkeiten effizient zu verwalten.

## Verwendete Technologien
* Java
* JavaFX (FXML) für das UI
* JSON für die Datenspeicherung
* JUnit für Unit-Testing
* Maven

English:

# Bank Simulation with Java

This project is an object-oriented bank simulation developed in Java as part of my computer science studies. It features a robust transaction system, a graphical user interface, and persistent data storage.

## Features & Architecture

* **Object-Oriented Design:** Structured modeling of banks, accounts, and various types of transactions.
* **Graphical User Interface (GUI):** A user-friendly interface built with **JavaFX** (using FXML) for easy data entry and transaction management.
* **Data Persistence:** To prevent data loss, all account balances and transaction histories are persistently stored using **JSON** and loaded upon application restart.
* **Quality Assurance:** Core functions and the transaction system are verified by automated **JUnit** tests.
* **Build Management:** The project is structured with **Maven** to efficiently manage dependencies and the build lifecycle.

## Technologies Used
* Java
* JavaFX (FXML) for the UI
* JSON for data storage
* JUnit for unit testing
* Maven
